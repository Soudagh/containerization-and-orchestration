# devstand-2

Стенд с телефонией для проверки голосовых сценариев.
- Телефония: есть, тестовая АТС на Asterisk
- SIP-транк: нет, звонки только внутри стенда через софтфон
- Диск: 100 ГБ
- Доп. хранилища: нет
- Версия платформы: текущая master

Заметки: годится для голосовых сценариев, если не нужны реальные входящие звонки от оператора.
